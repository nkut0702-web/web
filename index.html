DevPulse - 開發者智能監控工作台

React 18 TypeScript Node.js WebSocket Chart.js 視覺化 TailwindCSS

DevPulse 是一個針對現代分散式團隊設計的即時監控儀表板。它解決了團隊需要跨多個服務查看日誌、延遲與伺服器健康度的痛點，提供流暢的單一視圖。

✨ 核心架構亮點

  • 雙向低延遲通訊：使用 WebSocket 實現伺服器事件推送，延遲低於 50ms，支援百萬級假資料流式渲染。
  • 模組化儀表板：基於 React 18 與自訂 Hook 設計元件化可拖曳卡片，記憶使用者自訂版面。
  • 高效渲染優化：引入虛擬列表（Virtual Scrolling）與 Web Worker 運算，確保在高速高頻圖表更新下幀率維持 60 FPS。

💡 學習與突破

在開發本專案的過程中，我深入實踐了 TypeScript 嚴格型別定義、狀態管理策略以及瀏覽器端高負載資料的效能優化技巧，建立了從架構設計到部署落地的完整全端經驗。
